# JVXMusic 🎵

Премиальный кроссплатформенный музыкальный плеер на базе **Kotlin Multiplatform (Compose Multiplatform)** для **Desktop (Windows)** и **Android**.

---

## ✨ Возможности
* 🎧 **Фирменный интерфейс JVX (Dark Theme & Emerald Accent)**: стильный темный интерфейс (WCAG AA), адаптивная верстка, градиентный Hero-баннер с адаптацией под обложку, боковое меню и очередь воспроизведения.
* ⚡ **Точная перемотка (Scrubbing)**: мгновенный отзывчивый скраббинг с превью времени и гарантированной синхронизацией аудиопотока.
* 📊 **Живой спектральный визуализатор**: 64-полосный анимированный аудио-спектр в реальном времени.
* 🎚️ **10-полосный эквалайзер с пресетами**: Flat, Bass Boost, Rock, Pop, Vocal, Classical и ручная настройка от -12 dB до +12 dB.
* ⏱️ **Таймер сна и скорость воспроизведения**: автовыключение с плавным затуханием звука (15/30/45/60 мин) и регулятор скорости (0.5x – 2.0x).
* 📜 **Синхронизированные слова песен (.lrc)**: автоматический поиск `.lrc` файлов и караоке-скроллинг в такт музыке.
* 🪟 **Мини-плеер и Drag & Drop**: компактный режим Always-On-Top и поддержка перетаскивания файлов и папок прямо в окно.
* 🔊 **Управление звуком**: плавный скраббер громкости с сохранением уровня и кнопкой быстрого отключения (Mute/Unmute).
* 🔀 **Честный Shuffle & Repeat**: воспроизведение без повторов, режимы All / One / Off.
* 📁 **Плейлисты и Избранное**: создание, переименование, удаление плейлистов, выделенный раздел «Любимые треки», сортировка по дате, названию и длительности.
* ➕ **Импорт треков и папок**: поддержка `.mp3`, `.wav`, `.m4a`, `.aac`, `.flac`, `.ogg` с извлечением ID3-метаданных и обложек.

---

## 🛠️ Стек технологий
* **Kotlin Multiplatform 2.1.0**
* **Compose Multiplatform 1.7.3**
* **Material 3**
* **VLC / libVLC & vlcj** (Основной движок воспроизведения Desktop с поддержкой pitch-preservation `scaletempo`, FLAC, OGG, Opus, MP3, WAV; автоматический fallback на JavaFX Media)
* **Android Media3 ExoPlayer & MediaMetadataRetriever** (Android)
* **Kotlinx Serialization & Coroutines**

## 🚀 Сборка и запуск

### Desktop (Windows)
```bash
# Запуск приложения в режиме разработки
.\gradlew.bat :desktopApp:run

# Сборка автономного дистрибутива
.\gradlew.bat :desktopApp:createDistributable

# Сборка инсталлеров MSI и EXE
.\gradlew.bat :desktopApp:packageMsi :desktopApp:packageExe
```

#### Воспроизводимая сборка нативных библиотек VLC:
Задача `:desktopApp:prepareVlcNatives` обеспечивает полностью детерминированную и воспроизводимую сборку:
1. Автоматически скачивает официальный 64-битный релизный архив VLC (версия `vlc.version` из `gradle.properties`) с официальных серверов VideoLAN.
2. Проверяет контрольную сумму архива по SHA-256 (`vlc.win64.sha256` из `gradle.properties`).
3. Извлекает `libvlc.dll`, `libvlccore.dll` и каталог `plugins`.
4. Удаляет неиспользуемые модули видео/3D/GUI для минимизации размера (экономия более 50 МБ).
5. Пересоздаёт оптимизированный `plugins/plugins.dat` через `vlc-cache-gen.exe`.
6. Лицензии `LICENSE` (GPLv3) и `THIRD_PARTY_LICENSES.md` автоматически упаковываются в корневой каталог дистрибутива инсталлера.

### Android
```bash
# Сборка релизного подписанного APK
.\gradlew.bat :androidApp:assembleRelease
```
Готовый подписанный APK появится в `androidApp/build/outputs/apk/release/androidApp-release.apk` (параметры подписи подтягиваются из локального `local.properties` или переменных окружения).
